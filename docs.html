01 • URL STATE ARCHITECTURE

How State Travels in the Link

Nothing is ever sent to a Dangerous.Business backend. All state is serialized in the URL hash fragment (which browsers never transmit in HTTP requests to servers).

Hash ParameterFormatPurpose
#s=<lz> LZ-String URI-compressed JSON Standard instant-open trip link containing route, expenses, playlist, notes, pins, and micro-modules.
#e=<b64url> PBKDF2 (100k SHA-256) + AES-256-GCM Password-encrypted trip payload. Unreadable without the crew passphrase.
&ai=<json> URL-encoded JSON delta patch Appended to any existing #s= or #e= link by an AI agent (or script) to add expenses, stops, pins, notes, or micro-modules without decompressing the hash.
#ai=<json> URL-encoded JSON state Creates a brand-new trip from scratch directly from an AI chat or external tool.

04 • UNIVERSAL TURING-COMPLETE MICRO-MODULE LANGUAGE

DB-Script Language Reference

🧩 Open WYSIWYG Card Creator →

Every micro-module's UI structure and interactive logic is defined in DB-Script (mm.code) with its persistent JSON state (mm.data) stored right in the URL. The sandboxed VM enforces a 25,000-step execution guard to prevent infinite loops.

Core Language & Control Flow

state k = exprInitializes state.k in the URL if undefined.
let x = exprDeclares a local variable for the current render/block.
set state.k = exprMutates persistent URL state (supports .prop and [idx]).
if / elif / else / endConditional branching (also supports single-line if ... then ... end).
while cond ... endTuring-complete looping (also while cond do ... end).
for item, i in arr ... endIterates arrays (crew, state.items, etc.) with index i.
fn name(a, b) ... return v ... endUser-defined functions with recursion support.

Built-in UI Primitives & Helpers

countdown exprRich calendar diff (43y 8mo 5d 12h ago or 1mo 8d 11h).
big expr sub=e badge=eLarge centered hero readout with optional badge & subtitle.
kv key, val copy=trueKey-value row with optional 1-tap Copy button.
check label, bool -> stmtInteractive toggleable checkbox row.
btn label right=e active=b -> stmtAction or poll button that executes stmt on tap.
input stateKey, ph btn=lbl -> stmtText input + submit button bound to state[stateKey].
pin label, lat, lon note=eGPS pin card with live distance, bearing & Walk Directions.
progress pct / row ... endProgress bar (0–100%) and horizontal flex row layout.
Helpers:timeDiff(), len(), push(), removeAt(), toggleIn(), pushPairs(), dropPin(), distMi(), compass(), round(), maxIn(), sum(), join(), includes(), now()
05 • PARKING & MEETUP PINS

Never Lose Your Car or Crew

Tap Drop Pin on Overview or Locations to drop a 🅿️ Parking Spot or 🤝 Meeting Place pin using your exact GPS or place search. Everyone in the crew sees the distance, compass bearing, estimated walk time, and 1-tap Google Maps / Apple Maps walking directions.

06 • SMART MERGE & 12-SLOT BACKUP VAULT

Zero Accidental Data Loss

Opening an updated link pops up a collapsible item-by-item diff (ONLY ON YOUR DEVICE, + NEW IN LINK, MODIFIED, IN BOTH) and automatically saves a timestamped snapshot in ⚙ Settings → Saved System Backups before merging or restoring.
